# Nadine Paco's Portfolio

A professional, fully responsive personal portfolio for Nadine N. Paco. The site presents her education, developing skills, career interests, strengths, and contact details honestly as a college student seeking her first entry-level professional opportunity.

## Technology

- TanStack Start and React 19
- TypeScript
- Tailwind CSS 4 with custom responsive CSS
- Lucide line icons
- Netlify hosting and deployment configuration

## Local Development

Install dependencies and start the local development server:

```bash
pnpm install
pnpm dev
```

The site is configured for deployment on Netlify through `netlify.toml`.

## Key Files

- `src/routes/index.tsx` — portfolio content, navigation, and interactions
- `src/routes/__root.tsx` — page metadata and Person structured data
- `src/styles.css` — visual system and responsive layouts
- `public/assets/nadine-paco-portrait.webp` — optimized uploaded portrait
- `public/robots.txt` and `public/sitemap.xml` — search crawler setup

The public canonical URL currently uses the assigned Netlify site address. Update the canonical URL, sitemap, robots file, and structured data together if a custom domain is connected later.
